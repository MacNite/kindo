Run the demo yourself

One command starts the complete setup (database, migrations, the Müller family and the app) on your own computer. You need Docker; nothing else, not even a configuration file.

curl -O https://raw.githubusercontent.com/MacNite/kindo/main/docker-compose.demo.yml
docker compose -f docker-compose.demo.yml up -d

Then open http://localhost:3000 and sign in with the login above.

docker compose -f docker-compose.demo.yml down   # stop and forget everything

Good to know

  • The demo resets itself every hour (KINDO_DEMO_RESET_MINUTES, 0 turns it off) and on every restart: its database lives in memory only.
  • Another port: KINDO_DEMO_PORT=8080 docker compose -f docker-compose.demo.yml up -d
  • The demo uses a public secret key. Never keep real family data in it; use the setup guide for that.
