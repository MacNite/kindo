Das sind die Müllers

Anna, Max, Lena und der kleine Paul wohnen in Freiburg. Routinen, Termine, Aufgaben, Einkaufslisten, Essensplan und Belohnungen sind ausgefüllt. Klickt euch durch das komplette Kindo, ändert, was ihr wollt, und schaut, wie es sich anfühlt.

▶ Live-Demo öffnen

Sie läuft direkt hier im Browser: ohne Anmeldung, ohne Installation. Eure Änderungen bleiben auf diesem Gerät, und Neu anfangen holt die Müllers so zurück, wie sie waren.

Die Demo selbst starten

Die Browser-Demo zeigt jeden Bildschirm, aber was einen eigenen Server braucht (Kalender, Fotoserver, Home Assistant, Kameras, das Kinderregal, Logins und das Koppeln der Wand) lässt sich dort nur anschauen. Ein Befehl startet die komplette Installation (Datenbank, Migrationen, Familie Müller und die App) auf eurem eigenen Rechner. Ihr braucht nur Docker, nicht einmal eine Konfigurationsdatei.

curl -O https://raw.githubusercontent.com/MacNite/kindo/main/docker-compose.demo.yml
docker compose -f docker-compose.demo.yml up -d

Dann http://localhost:3000 öffnen und als Anna anmelden:

E-Mailanna@demo.kindo Passwortkindo-demo 
docker compose -f docker-compose.demo.yml down   # stoppen und alles vergessen

Gut zu wissen

  • Die Demo setzt sich jede Stunde zurück (KINDO_DEMO_RESET_MINUTES, 0 schaltet das ab) und bei jedem Neustart: Ihre Datenbank liegt nur im Arbeitsspeicher.
  • Ein anderer Port: KINDO_DEMO_PORT=8080 docker compose -f docker-compose.demo.yml up -d
  • Die Demo nutzt einen öffentlichen Schlüssel. Keine echten Familiendaten darin ablegen; dafür gibt es die Einrichtungsanleitung.
